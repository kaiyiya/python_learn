# Adam 优化器速读笔记

## 关键概念
- **用途**：在深度学习中加速梯度下降，减小学习率选择带来的麻烦，尤其适用于稀疏梯度、多噪声场景。
- **核心思路**：综合一阶动量（均值）与二阶动量（方差），动态为每个参数调整学习率。
- **优势**：自适应学习率、收敛快、几乎无需复杂超参搜索，比 SGD 更稳定。

## 工作原理（极简版）
| 步骤 | 说明 |
| --- | --- |
| 1. 梯度统计 | 记录当前梯度 `g` 的指数滑动平均：<br> `m_t = β₁ · m_{t-1} + (1-β₁) · g_t` <br> `v_t = β₂ · v_{t-1} + (1-β₂) · g_t²` |
| 2. 偏差修正 | 初期动量偏小，使用：<br> `m̂_t = m_t / (1-β₁ᵗ)` ，`v̂_t = v_t / (1-β₂ᵗ)` |
| 3. 参数更新 | `θ_t = θ_{t-1} - η · m̂_t / (√(v̂_t) + ε)` |

理解方式：`m̂_t` 决定方向（像带记忆的动量），`√(v̂_t)` 决定步长大小（梯度越大，分母越大，步子越小）。

## 与其他方法对比
- **SGD**：固定学习率，容易震荡或停滞。
- **Momentum**：加速方向，但没有按元素调节步长。
- **RMSProp**：按元素缩放步长，但缺少动量记忆。
- **Adam**：把 Momentum + RMSProp 的优点结合起来。

## 示例代码入口
- 脚本位置：`learning/adam_demo/adam_example.py`
- 运行命令（PowerShell）：`python learning\adam_demo\adam_example.py`
- 输出：每 40 个 epoch 打印一次损失、权重与偏置，最后展示训练结果。

## 使用建议
- **学习率**：`0.001`~`0.01` 是较安全的起点，示例为了更快收敛用的是 `0.05`。
- **β₁, β₂**：常用默认 `0.9` 与 `0.999`，除非需要极快响应。
- **ε**：防止除零的小常数，一般不用改。

## 快速回忆口诀
> 记梯度，算均方；偏差校，除方根；自适应，省调参。
